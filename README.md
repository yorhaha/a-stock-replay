# 上证指数回撤复盘 · 2006—2026

一个无依赖的静态可视化页面，复盘 2006—2026 年上证指数的八轮波段回撤。

## 内容

- **总览**：20 年指数走势、回撤区间、20 日均成交额，支持对数/线性切换。
- **周期**：八轮回撤的峰值→谷值、最大回撤、持续时长、单日最大跌幅、成交额萎缩、见底后表现、修复前高，以及指数分化与政策/市场节点。
- **结构**：三类驱动矩阵（内因、加速器、催化剂）与三段反转框架（政策底、市场底、主升反转）。
- **数据**：全量指标表，可下载 `assets/episodes.csv`。

## 数据口径

- 指数：上证指数（000001）日线；辅助指数：沪深300、上证50、中证1000、创业板指。
- 区间：2006-01-03 至 2026-11-20。
- 最大回撤：区间内盘中最高点至盘中最低点。
- 走势曲线：收盘价。
- 成交额萎缩：区间峰值日 20 日均成交额 ÷ 区间最低 20 日均成交额。
- 见底后 12 个月：谷值日收盘后第 250 个交易日。
- 修复前高：谷值后首个收盘价不低于峰值日收盘价的交易日。
- 数据来源：东方财富日线接口。

## 本地预览

```bash
python3 -m http.server 4173
# http://localhost:4173
```

## 重新生成数据

原始日线保存在 `data_raw/`。重新生成：

```bash
python3 scripts/build_data.py
```

生成 `assets/data.js` 与 `assets/episodes.csv`。

## 部署

仓库根目录直接作为 GitHub Pages 发布源（`main` / `/`），无需构建步骤。
